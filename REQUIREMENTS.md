1. **Smooth gameplay** — 20 TPS, no lag spikes
2. **Waiting Cage** — Players spawn in restricted area (20x20, Adventure) until admin triggers "Go!"
3. **Whitelist** — Easy web-based whitelist management
4. **Discord integration** — Chat bridge, join/leave notifications
5. **Live map** — Bluemap or similar web map
6. **Backups** — Automatic daily backup
7. **Clear communication** — MOTD, status page showing who's online
